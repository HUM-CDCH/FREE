# Apply FREE-technical Prose Tolerant Matching

- [ ] In `prototypes/studio/src/markdownAnchorMatch.ts`, add `normalizeTolerantText(text)` modelled on FREE-technical prose matching: lowercase, strip diacritics, normalize dash variants, collapse whitespace, remove most punctuation, and return token-friendly text.
- [ ] In `markdownAnchorMatch.ts`, add `candidateFragments(snippet, value)` that returns ordered prose candidates: full snippet; text after one leading label (`Skelet:`, `Gravudstyr:`, etc.); value-centered snippet fragments when `value` appears; ellipsis-split fragments around `...`; and sentence fragments above a minimum token/character threshold.
- [ ] In `markdownAnchorMatch.ts`, add `findUniqueTolerantScopedRange(markdown, candidate, scope)` that searches only within `sourceScope`, maps normalized/token-tolerant matches back to raw markdown ranges, and returns a range only when exactly one candidate occurrence is found.
- [ ] In `markdownAnchorMatch.ts`, add `findTolerantScopedMarkdownAnchorMatch(markdown, anchors, value, snippet, scope)` that tries `candidateFragments`, calls `findUniqueTolerantScopedRange`, and resolves the winning range through the existing `resolveOccurrence` bbox-union path.
- [ ] In `findScopedMarkdownAnchorMatch(...)`, keep the current exact primary/fallback behavior first, then call `findTolerantScopedMarkdownAnchorMatch(...)` only when exact matching returns null.
- [ ] In `prototypes/studio/src/EvidenceHighlightLayer.tsx`, keep `findTableCellRects -> findAnchorRects -> findScopedHintPageTextRects`; update `findAnchorRects` only as needed to pass both `highlight.value` and `highlight.snippet` into the tolerant anchor matcher.
- [ ] In `EvidenceHighlightLayer.tsx`, keep `findScopedHintPageTextRects` as the no-anchor fallback, but gate it with the same prose-only checks: no row/column hints, snippet not table-like, unique scoped canonical candidate, and non-null `hintPage`.
- [ ] In `prototypes/studio/src/evidenceTextSearch.ts`, either reuse existing `normalizeForMatch`/`searchValueAnchoredBySnippet` or add a small tolerant-token helper for hint-page PDF fallback; do not restore page-wide or document-wide search.
