# Labeling notes: buchvaldek-1970-vikletice-tables-de

- Shape: German tables volume of the Vikletice Corded Ware cemetery. The sampled `finds` records are rows of the find-class tables: Tabelle 2 Hammeräxte (p35), Tabelle 3 Keulenköpfe (p36), Tabelle 4-6 Beile BL 1/2/4 (p38-39), Tabelle 8 Schleifsteine (p63), Tabelle 9 Knochengeräte (p64), prose on Muschelschmuck/Marmoranhänger (p64), Tabelle 10a Tierzahnschmuck (p65), Tabelle 10b Kupferschmuck (p66). Site name from prose p31/p68; the grave-length table is on p2.
- Record identification: every sampled record maps to exactly one table row via `context` (material + weight + note); no invented or merged records found. Extractor `finds` indices are offset by one against Tabelle 2 (one Hammeraxt row skipped), consistent afterwards. Ambiguous-looking contexts (Schleifsteine 60/1963 vs 121/1963, both J/270 gr) were resolved by index order.
- Convention `type` (17 claims) and `material: Kupfer` (2 claims): labeled supported with the table caption as gold anchor (e.g. 'Tabelle 2: Hammeräxte', 'Tabelle 10b: Kupferschmuck'); no row cell carries the class word. Flip these to (c) if captions are not accepted as per-row evidence; the notes name the row.
- Convention `note` concatenations (5 claims, marked "supported (concat of 2 cells...)" in the note): the extractor joined two adjacent cells of the same row (Tierzähne + Lage; Schmuckart + Maße), sometimes dropping trailing text ('L.?,', 'Draht 0 etwa 2 mm.'). Every retained token is verbatim; labeled supported with both cell anchors. Flip to (c) if a single anchor must carry the whole value.
- Bracketed weights: '(30)' for 104/1963 (also '(40)', '(130)' in contexts) mark heavily damaged pieces per the tables' note 10/14; labeled supported as 30.
- OCR damage: Tabelle 6 (BL 4) has a numeric header row only ('101 | H | 12' for 10/11/12), so its cells (weight 40 for 82/1964 B.5, note for 71/1964) carry no column name in `context`; column 11 = Gewicht by the Tabelle 4/5 layout. Tabelle 4 header reads 'Gewicht m gr'; Schleifstein cell 'Sandslein', 'Sandstein i'; Kupferschmuck 'Spiral/ röllchen', soft hyphens ('Spiral­ röllchen', 'Ver­ witterung') inside cell text; '0' stands for the diameter sign throughout. Extractor values normalise these.
- Knochengeräte: the extractor mapped the 'Gerät' column to `note` and the 'Tier' column to `material` (Hausrind, Schaf oder Ziege); labeled by the cell text, not by column semantics.
- Top-level context 'child_grave_count: 1, child_grave_length_min_cm: 100' contradicts p2 ('Kindergräber (19)', 'kl. Länge ... 65 cm'), but those values were not in the sample; only `site` was judged.
- DOUBT: finds[81].material 'Tierzähne' (140/1963): 'Tierzähne (Nachahmungen)' is only the column header; the row reads 'etwa 11(7) Stück', i.e. 7 bone imitations, so the material is mixed. Labeled [] (b). A lenient reading via the caption 'Tierzahnschmuck' would support it.
